Paramètres

Tout ce que le détecteur utilise est réglable ici. En ligne, « Enregistrer » écrit tes réglages dans le dépôt GitHub du détecteur, qui les applique à la vérification suivante (au plus une heure). Dans cette maquette, l'enregistrement n'est pas encore branché.

Connexion à ton dépôt GitHub

Pour enregistrer les paramètres et retrouver tes niveaux sur tous tes appareils, la page a besoin d'un jeton GitHub. Il reste dans ce navigateur, nulle part ailleurs.

  1. GitHub → photo de profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access : Only select repositories → detecteur-btc.
  3. Permissions : Contents en Read and write, et Actions en Read and write.
  4. Copie le jeton (il commence par github_pat_) et colle-le ci-dessous.
